## 💼 Adobe Stock Submission Checklist & Metadata Tips

### 1. Keywording Strategy (Tags)
Always include 35–45 descriptive keywords. Core keyword groups to include for every design:
- **Core Numbers & Year:** `2027`, `New Year 2027`, `Happy New Year 2027`, `Twenty Twenty-Seven`.
- **Subject Type:** `typography`, `numerical`, `lettering`, `signage`, `monogram`, `calligraphy`.
- **Style Specifics:** (e.g., `minimalist`, `gold foil`, `chrome 3D`, `retro 70s`, `cyberpunk neon`, `swiss grid`).
- **Commercial Usage:** `banner`, `copy space`, `header`, `greeting card`, `invitation`, `background`, `wallpaper`, `commercial stock`.

### 2. Quality Control Before Upload
- **Inspect Text Accuracy:** Check whether AI rendered extra digits or deformed glyphs. If the letters/numbers aren't razor-sharp, open in Photoshop/Illustrator and retouch or vector-trace.
- **Upscaling:** Adobe Stock requires high resolution (minimum 4MP, but 8K / 300 DPI is preferred for premium price tiers). Upscale using Topaz Gigapixel, Magnific, or Photoshop Super Resolution.
- **Property/Model Releases:** These are typography/abstract designs, so no model releases are needed. Ensure no real trademarks (e.g., Apple, Nike, actual brand logos) accidentally appear.
- **Labeling:** Mark "Created using Generative AI tools" in Adobe Stock Contributor Portal according to Adobe's contributor requirements.
